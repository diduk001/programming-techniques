# Лабораторные работы по Методам программирования

Для запуска python-скриптов используется менеджер проектов [uv](https://docs.astral.sh/uv/). Чтобы запускать скрипты, нужно:
1) Создать виртуальное окружение: `uv sync`
2) Активировать его: `source .venv/bin/activate`
